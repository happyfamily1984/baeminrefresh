# 배민리프레시

화면에 떠 있는 동그란 버튼 하나로 **배민커넥트 앱을 완전히 종료하고 다시 실행**하는 안드로이드 앱입니다.

## 기능

- **플로팅 버튼**: 다른 앱 위에 항상 떠 있는 버튼
  - 짧게 누르기 → 배민커넥트 강제 종료 후 재시작
  - 누른 채 끌기 → 원하는 위치로 이동 (위치 저장, 화면 밖으로 안 나감)
  - 길게 누르기 → 배민리프레시 설정 화면 열기
- 버튼 크기·불투명도 조절, 위치 초기화
- 앱 안에서 단계별 초기 설정 안내 (각 단계 완료 여부 자동 표시)
- 재부팅 후에도 켜 두었던 버튼 자동 표시

## 동작 원리

안드로이드에서는 일반 앱이 다른 앱을 직접 종료할 수 없습니다.
그래서 배민리프레시는 **접근성 서비스**를 이용해 다음을 자동으로 수행합니다.

1. 배민커넥트의 `설정 → 앱 정보` 화면을 연다
2. `강제 중지` → `확인` 버튼을 대신 누른다
3. 배민커넥트를 다시 실행한다

버튼을 누르면 '앱 정보' 화면이 잠깐 보였다가 사라지는 것이 정상입니다.
배민커넥트 패키지명은 설치된 앱 이름("배민커넥트")으로 자동 탐지하며, 못 찾으면 앱 목록에서 직접 고를 수 있습니다.

## 설치

1. 휴대폰에서 아래 링크를 열어 APK를 내려받습니다. (항상 최신 버전)
   https://github.com/happyfamily1984/baeminrefresh/releases/latest/download/BaeminRefresh.apk
2. 내려받은 `BaeminRefresh.apk`를 열어 설치합니다 ('출처를 알 수 없는 앱 설치' 허용 필요).
   - **Play 프로텍트가 설치를 막으면** 아래 [Play 프로텍트에 막힐 때](#play-프로텍트에-막힐-때)를 참고하세요.
3. 앱을 열고 화면 안내에 따라 설정합니다.
   1. 배민커넥트 앱 선택 (보통 자동 선택됨)
   2. 다른 앱 위에 표시 허용
   3. 접근성 서비스 켜기 — 안 켜지면 `앱 정보 → ⋮ → 제한된 설정 허용` 후 다시 시도
   4. (권장) 알림 허용, 배터리 최적화 제외

## Play 프로텍트에 막힐 때

Play 스토어 밖에서 받은 앱이 접근성 기능을 쓰면, 구글 Play 프로텍트가 설치를 막는 경우가 많습니다.
배민리프레시는 인터넷 권한도 없고(데이터를 밖으로 보낼 수 없음), 접근성은 '설정' 앱 화면에서만 동작하도록 제한되어 있습니다.

**방법 1. 경고 창에서 그대로 설치**

1. 'Play 프로텍트에서 차단함 / 안전하지 않은 앱' 창이 뜨면 **세부정보 더보기**(또는 ∨ 화살표)를 누릅니다.
2. **그래도 설치**를 누릅니다.
3. '앱 검사를 위해 보내기' 창이 나오면 **보내지 않음**이나 **보내기** 중 아무거나 눌러도 됩니다.

**방법 2. '그래도 설치' 버튼이 없을 때 (Play 프로텍트 잠시 끄기)**

1. **Play 스토어** 앱 → 오른쪽 위 **프로필 사진** → **Play 프로텍트**
2. 오른쪽 위 **⚙ 톱니바퀴** → **Play 프로텍트로 앱 검사** 끄기 → 확인
3. APK를 다시 열어 설치합니다.
4. 설치가 끝나면 같은 곳에서 **Play 프로텍트로 앱 검사**를 **다시 켭니다.**
   (다시 켜도 이미 설치된 배민리프레시는 지워지지 않지만, 혹시 '앱 삭제 권장' 알림이 오면 **무시**를 누르세요.)

**그 밖에**

- 카카오톡/브라우저에서 바로 열면 막히는 경우가 있습니다. **내 파일(파일 관리자) → 다운로드** 폴더에서 APK를 눌러 설치해 보세요.
- '출처를 알 수 없는 앱 설치' 허용 창이 뜨면, APK를 연 앱(내 파일, Chrome 등)에 **허용**을 켜 주세요.

## 직접 빌드

```bash
./gradlew assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

요구 사항: JDK 17, Android SDK (compileSdk 35). 최소 지원 버전 Android 8.0 (API 26).

### 서명 키

배포용 APK는 저장소에 없는 별도 키로 서명합니다. CI는 GitHub Secret 두 개를 사용합니다.

- `SIGNING_KEYSTORE_BASE64`: 키 파일(alias `baeminrefresh`)을 base64로 인코딩한 값
- `SIGNING_PASSWORD`: 키 비밀번호

키 파일을 잃어버리면 이미 설치한 사람들은 앱을 지우고 다시 설치해야 하므로, 키 파일은 따로 안전하게 보관하세요.
로컬에서 키 없이 빌드하면 개인 디버그 키로 서명됩니다.

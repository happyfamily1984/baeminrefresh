# 배민리프레시 재구현 프롬프트 (워터 타이머·워터 모드·개인 연동·개인 API 키 제외)

아래 내용을 새 Claude Code 세션에 그대로 붙여 넣으세요.

---

너는 안드로이드 앱 개발자야. 배달 라이더용 플로팅 버튼 앱 **"배민리프레시"**를 처음부터 만들어 줘.
아래 명세대로 **똑같이** 동작해야 해. 단, **워터 타이머(물방울 버튼)·워터 모드·일기장 앱 연동은 만들지 마.** 개발자 개인 API 키도 앱에 넣지 않고, 사용자가 자기 키를 입력하는 방식으로 만들어.

## 0. 일하는 방식

- 나한테는 항상 **한국어, 쉬운 말**로 답해. 결과는 "무엇이 바뀌었나 / 쓰는 법 / 알아둘 점" 순서로 짧게.
- 이 환경에는 안드로이드 SDK와 기기가 없어. **로컬 빌드는 못 하고, GitHub Actions 빌드 성공까지만 확인**해. 기기 테스트는 내가 직접 하니까, 확인 못 한 건 "기기에서 확인 필요"라고 분명히 말해.
- **먼저 전체 계획(단계별 순서)을 보여 주고 내 확인을 받은 뒤** 시작해. 그다음 아래 "11. 만드는 순서"대로 단계마다 빌드 성공을 확인하면서 진행해.
- 단계마다 `versionCode`/`versionName`을 올리고, 커밋 메시지는 한국어로 써.
- PR은 내가 요청하기 전에는 만들지 마.
- 저장소 루트에 `CLAUDE.md`(새 세션 인수인계 문서: 버전, 구조, 설계 규칙, 기능 이력, 기기 검증 상태)를 만들고, 기능을 바꿀 때마다 갱신해.

## 1. 기술 조건

- 패키지 `com.baeminrefresh.app`, 앱 이름 "배민리프레시"
- Kotlin, **View 기반(Compose 아님)**, minSdk 26 / targetSdk 35 / compileSdk 35
- AGP 8.7.x, Kotlin 2.0.x
- 라이브러리: `androidx.core:core-ktx`, `appcompat`, `material`(Material3)만. 그 밖의 외부 라이브러리는 쓰지 마.
- 테마: `Theme.Material3.DayNight.NoActionBar`, 투명 화면용 `Theme.BaeminRefresh.Translucent`
- SharedPreferences 하나(`baemin_refresh`)에 설정을 모두 저장(`Prefs.kt`). 스티커·재시작 앱·폴더 목록은 JSON으로.

## 2. 공통 규칙

- 뒤로가기를 누르면 이전 동작(선택 모드·수정 중·열린 창)을 취소하거나 이전 화면으로 돌아가.
- 첫 화면에서 뒤로가기를 누르면 **"앱을 종료하겠습니까?"**를 묻고, "예"를 누르면 종료해.

## 5. 플로팅 버튼 엔진 (모든 버튼 공통)

- **포그라운드 서비스**: 타입 `specialUse`(+녹음 중 `microphone`, +녹화 중 `mediaProjection`). 상시 알림은 "배민리프레시 플로팅 버튼 사용 중"에 "버튼 끄기" 동작.
- **오버레이**: 접근성이 연결돼 있으면 `TYPE_ACCESSIBILITY_OVERLAY`(통화 화면 위에도 보임), 아니면 `TYPE_APPLICATION_OVERLAY`. 접근성이 붙거나 떨어지면 다시 그리기(`refreshOverlayType`).
- **모양**: 원형, 흰 테두리 2dp, 그림자. 크기·투명도는 설정값을 따름. 크기가 바뀌면 0.25초 모아서 한 번에 다시 그리기.
- **드래그**: 끌어서 옮기고, 놓으면 아래 규칙으로 정렬한 뒤 애니메이션으로 이동하고 위치 저장.
  1. 다른 버튼과 (버튼 크기 + 반 개) 안쪽이면 그 버튼 위나 아래로 세로로 붙임(간격 = 설정 간격).
  2. 아니면 가장 가까운 벽까지 버튼 반 개보다 가까울 때 그 벽에 붙임.
  3. 좌우 벽에 붙을 때, 반대편 벽 버튼과 높이가 (크기 2/3) 안쪽이면 높이를 맞춤.
  4. 다른 버튼과 겹치면 겹치지 않는 자리로 밀어냄.
- **간격 설정이 바뀌면** 같은 세로줄에 붙어 있는 버튼들 사이를 새 간격으로 다시 맞춤.
- **처음 위치**:
  - 기본 재시작 버튼: 오른쪽 끝, 높이 60%
  - 스티커: 왼쪽, 30%부터 아래로
  - 버튼 종류마다 정한 기본 위치(겹치면 밀어냄)
- **탭 / 길게**: 0.6초 이상 누르면 길게 누르기(떼기 전에 바로 반응), 살짝 커지는 반응.
- **숨기는 때**:
  - 실험실 "가로모드 시 플로팅 아이콘 일시정지"가 켜져 있고 가로일 때 → 전부 숨김
  - 화면 꺼짐·Always On Display·잠금화면 → 숨김. `isInteractive && !isKeyguardLocked`일 때만 보이고, SCREEN_OFF/SCREEN_ON/USER_PRESENT로 다시 그림. 예외: 통화 중 잠금화면이면 통화 증폭 버튼만.
  - 화면 녹화 중 → 숨김
- **재진입 주의**: 설정 변경 리스너가 메인 스레드에서 동기로 `buildAll()`을 부르므로, `buildAll()` 안에서 설정을 저장해야 하면 `handler.post{}`로 미룰 것.
- **버튼 키**(폴더·위치 저장용): `"main"` · `"rapp:<pkg>"` · `"sticker:<pkg>"` · `"capture"` · `"voice"` · `"optimize"` · `"reply"` · `"screenrec"`. 통화 증폭 버튼은 임시 버튼이라 폴더에 넣을 수 없음.

## 6. 기능 상세

### 6-1. 재시작 (핵심)

- 접근성으로 진행: 앱 정보 화면 열기(`ACTION_APPLICATION_DETAILS_SETTINGS`, NEW_TASK|CLEAR_TASK|NO_HISTORY|EXCLUDE_FROM_RECENTS)
  → "강제 중지" 버튼 찾아 누르기(id `com.android.settings:id/force_stop_button` 또는 글자 "강제 중지/강제중지/강제 종료/Force stop")
  → 확인 창 "확인/OK/예" 누르기
  → 0.6초 뒤 그 앱 다시 실행.
- 상태 기계로 0.25초마다 확인하고, 8초 넘으면 실패로 끝냄.
- 이미 중지된 앱이면 바로 실행.
- `forceStopOnly`(다시 실행 없이 종료만)도 제공.
- 진행 중에는 버튼이 회전하고, 결과는 토스트로 알림. 재시작 효과음은 음소거.
- 배민커넥트는 `TargetApps`가 이름·패키지 점수로 자동 감지하고, 못 찾으면 사용자가 목록에서 고름.

### 6-2. 앱 스티커 · 리프레시 앱

- 실행 가능한 앱 목록(아이콘+이름)에서 고르기. 배민커넥트로 보이는 앱이 맨 위.
- **업무 프로필(멀티 프로필) 앱도 스티커 가능**:
  - `LauncherApps.profiles` 중 내 프로필이 아닌 것의 앱을 목록에 추가(이름 끝에 💼, 💼 뱃지 아이콘 `getBadgedIcon`)
  - 저장은 `"패키지@프로필번호"`(UserManager serial)
  - 실행은 `LauncherApps.startMainActivity`. 프로필이 일시 중지면 `requestQuietModeEnabled(false)`
  - 프로필이 꺼져 있는 동안엔 스티커를 지우지 말고 건너뜀
- 앱이 삭제되면 스티커 자동 정리.
- 리프레시 앱(재시작 앱)은 내 프로필 앱만.

### 6-3. 폴더

- 설정 화면에서 버튼 2개 이상 골라 만들기.
- 닫힌 폴더의 멤버 버튼은 화면에 안 올림.
- 탭하면 멤버들이 폴더 바로 아래(공간 없으면 위)에 세로로 펼쳐짐.
- 펼친 멤버를 누르면 실행하고 폴더를 닫음(음성 버튼은 녹음 중이라 열어 둠).
- **0.28초 안에 두 번 누르면** `FolderPickerActivity`(투명 창): 여러 앱 체크 → 스티커로 만들어 그 폴더에 넣기(업무 프로필 앱 포함).
- 펼친 멤버는 위아래로만 끌어서 **순서 바꾸기**(위치 저장 안 함).
- 1.5초 길게 → 폴더가 사라지고 버튼들이 그 자리에 다시 나옴.
- 없어진 버튼은 폴더에서 자동으로 빠지고, 2개 미만이면 폴더 삭제.

### 6-4. 실험실: 가로모드 시 일시정지

- 가로일 때 모든 플로팅 아이콘을 숨겼다가 세로로 돌아오면 다시 표시.

### 6-5. 실험실: 📷 화면 캡쳐

- 접근성 `takeScreenshot`(안드로이드 11+)으로 캡쳐.
- 캡쳐 직전 플로팅 버튼을 잠깐 숨기고, 상태바·내비게이션바를 잘라 갤러리(Pictures)에 저장.
- "화면을 저장했어요 (갤러리 확인)" 토스트.

### 6-6. 실험실: 🎙 음성 입력

- 탭 → 말하기 → 다시 탭 → 커서가 있는 입력창에 글 넣기.
- 입력은 접근성으로 모든 앱 창을 뒤져 입력창을 찾음(입력 포커스 → 포커스된 편집 칸 → 화면 맨 아래 편집 칸 순). 클립보드 붙여넣기(ACTION_PASTE), 안 되면 SET_TEXT. 입력창을 못 찾으면 클립보드에 복사.
- **제미나이 받아쓰기(기본 켜짐)**:
  - `MediaRecorder`(AAC_ADTS, 16kHz 모노, 32kbps)로 `filesDir/voice_pending/<시각>.aac`에 녹음.
  - 말이 멈춰도 끊기지 않고 다시 누를 때까지 녹음(최대 2시간). 버튼에 분:초 표시.
  - 녹음 중에는 오디오 포커스를 잡아 유튜브·음악을 멈추고, FGS 타입에 `microphone` 추가.
  - 다시 누르면 `ReplyAi.transcribe`로 받아쓰기(버튼 노랑).
    - 12MB 이하는 inlineData, 넘으면 Files API 재개 업로드 후 fileData.
    - 프롬프트: 들린 말만, 요약·추가 금지, 띄어쓰기·문장부호, 군말 빼기, 숫자·금액 정리(삼천오백 원 → 3,500원), 배달 용어 철자 참고, 말이 없으면 `[없음]`.
  - 성공하면 파일 삭제. 실패하면 남겨 두고 다음 탭 때 먼저 다시 보내기.
  - 녹음 내내 소리가 없으면 "말소리가 들리지 않았어요".
- **폰 음성 인식(예비)**: 비밀번호나 키가 없거나 제미나이를 끄면 `SpeechRecognizer`.
  - 끊기면 자동 재시작하고 결과를 모아 마지막에 한 번에 입력.
  - 중간 결과 보존, 신뢰도 높은 후보 선택, 배달 용어 힌트.
  - 독점 오디오 포커스, 시작음 음소거.
  - "📴 오프라인 우선" 옵션.
- 배달 용어 힌트: 배민, 배민커넥트, 쿠팡이츠, 카카오 T 픽커, 픽업, 배달, 배달 완료, 주문, 고객님, 문 앞, 공동현관, 비밀번호, 도착, 출발, 수락, 거절.

### 6-10. 실험실: 💬 답변 추천 (카카오톡·텔레그램·스레드)

- **카카오톡·텔레그램 대화방**:
  - 접근성으로 화면 글자를 위→아래로 읽음(입력창 줄 아래는 제외).
  - 말풍선 위치로 `[오른쪽]`(나)·`[왼쪽]`(상대) 표시. 3000자 넘으면 최근 쪽만.
  - 제미나이 프롬프트: **짧은 대답·정중한 인사·추임새만**. 새 정보·약속·의견을 만들지 않음. 모르면 "확인해 보고 말씀드릴게요". 1~2문장, 사용자 말투를 따름. temperature 0.7.
- **스레드(`com.instagram.barcelona`)**:
  - 답글 칸 안내 글자 "X님에게 답글 남기기"(영문 "Reply to X")에서 상대 아이디를 얻음.
  - 입력칸에 가장 가까운 그 아이디 **바로 아래 본문만** 읽음.
  - 제외: 같은 줄의 시간·커뮤니티, 이미지 설명, 링크 미리보기(도메인부터), 좋아요 수, '활동 보기', 다음 사람 아이디.
  - 아이디 칸이 "아이디 16시간"처럼 붙어 있거나, 설명에만 있거나, 본문과 합쳐진 경우도 처리.
  - 못 찾으면 화면 글자 8개를 설정 화면 "🔎 지난번 실패 기록"에 남김(길게 눌러 복사).
  - 프롬프트: 공감·의견·대화를 이어 갈 질문 1~3문장. 사실 지어내기·욕설·비하 금지. temperature 1.0.
- 결과는 **입력창 글을 통째로 교체**(전송·게시는 누르지 않음).
  - 스레드 답글 칸이 접혀 있으면 눌러 펼친 뒤 입력(0.7초 간격 3회 시도).

### 6-11. 실험실: ⏺ 화면 녹화 (안드로이드 10+)

- 탭 → `ScreenRecordActivity`가 `createScreenCaptureIntent` 허용 창 → `ACTION_SCREENREC_START`로 서비스에 전달.
- 서비스는 FGS를 `mediaProjection`(+마이크 옵션, +specialUse) 타입으로 올린 **뒤** `getMediaProjection` → 콜백 등록.
- 녹화 설정: `MediaRecorder`(H.264 mp4, 화면 비율 그대로 긴 쪽 ≤1920, 짝수, 30fps, 8Mbps, 옵션 시 마이크 AAC 128k/44.1k) → MediaStore `Movies/배민리프레시`(IS_PENDING).
- **녹화 중엔 플로팅 버튼을 모두 숨김.** 허용 창이 찍히지 않게 0.5초 뒤 녹화 시작.
- 끝내는 방법:
  - 녹화 알림 "■ 녹화 끝내기"
  - 화면 끄기(SCREEN_OFF)
  - 옵션 "작은 ■ 정지 버튼 남기기"(반투명 45%). 알림이 꺼져 있으면 자동으로 표시.
  - 시스템이 멈출 때(onStop)
- 저장 후 "화면 녹화를 저장했어요" 알림(누르면 재생). 너무 짧아 실패하면 MediaStore 항목 삭제.
- 녹화 알림 채널 "화면 녹화"(LOW).

### 6-12. 실험실: 🛡️ 배민커넥트 꺼짐 방지 + 꺼짐 기록

- **A. 점검·바로가기**:
  - 배민커넥트·배민리프레시가 배터리 최적화에서 빠져 있는지 ✅/⚠️ 표시(`isIgnoringBatteryOptimizations(pkg)`)
  - "배민커넥트 배터리 설정(제한 없음)" → 앱 정보
  - "삼성 절전 예외 앱 설정" → `com.samsung.android.lool` BatteryActivity, 안 되면 최적화 목록
  - "사용 기록 접근 허용"
- **B. 자동 다시 켜기(토글, 수동)**: FloatingService와 함께 15초마다 확인.
  - 감지 조건:
    1. 배민커넥트 `FLAG_STOPPED`가 false→true
    2. UsageEvents `FOREGROUND_SERVICE_STOP`이 배민커넥트 화면 밖에서 생기고, 그 뒤 다시 START가 없음
  - 감지하면 런치 인텐트로 다시 켜고, 1.8초 뒤 보던 앱으로 복귀(런처면 홈). 화면 꺼짐·잠금이면 복귀 생략.
  - 다시 켜지 않는 경우:
    - 우리 재시작·폰 최적화 중이거나 끝난 뒤 45초 안
    - 배민커넥트 화면이나 설정 앱이 앞에 있음(직접 끈 것으로 봄)
  - 1분에 1회, 30분에 6회까지. 넘으면 "배터리 설정을 확인해 주세요" 토스트.
- **꺼짐 기록**: 토글과 상관없이 감지할 때마다 남김(최대 60개, JSON).
  - 시각, 종류(강제 중지됨 / 상시 알림(운행) 멈춤), 보던 앱, 남은 메모리(부족 여부), 화면 켜짐·꺼짐, 배터리 %, 절전 모드, 처리 결과
  - 카드에 "최근 24시간 n번 · 전체 n번 (메모리 부족 n번)" 요약
  - "📋 꺼짐 기록 보기"(복사·지우기)

## 7. 제미나이 API 키 (답변 추천·음성 받아쓰기 공용)

- **개발자 키를 앱·저장소·빌드(GitHub Secret 포함)에 넣지 마.** 사용자가 자기 키를 직접 입력하는 방식으로 만들어.
- 실험실 '답변 추천' 카드에 "제미나이 API 키" 입력칸(여러 개는 줄바꿈으로)과 "확인" 버튼.
  - 키는 폰 안에만 저장(EncryptedSharedPreferences를 쓰지 않는다면 일반 Prefs라도 앱 내부 저장소에만).
  - 화면에는 키를 가린 채(앞 4자리만) 보여 줌.
  - 상태 표시: "✅ 준비됐어요 (API 키 n개, 모델 4개)" / "키를 넣어 주세요" / "키가 맞지 않아요"(가벼운 테스트 요청으로 확인).
  - 키 발급 안내 링크: Google AI Studio.
- 키가 없으면 답변 추천은 "키를 넣어 주세요" 안내. 음성 입력은 자동으로 폰 음성 인식을 씀.
- **모델 순서**: `gemini-3.1-flash-lite` → `gemini-3.5-flash-lite` → `gemini-flash-lite-latest` → `gemini-3.8-flash`
  - 모델 × 키 순서로 시도하고, 지난번에 성공한 조합을 먼저 시도
  - 404·기타 400 → 다음 모델
  - 401/403/429/5xx·키 오류 → 다음 키
  - 인터넷이 없으면 바로 안내
- 엔드포인트 `https://generativelanguage.googleapis.com/v1beta/models/<모델>:generateContent`, 헤더 `x-goog-api-key`.
- 처음 켤 때 "누를 때 읽은 대화·녹음이 구글(제미나이)로 전송돼요" 안내와 동의를 받기.
